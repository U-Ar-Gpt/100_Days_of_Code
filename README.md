# 💻 100 Days of Code – C Programming

---

## 📌 About

This repository contains my solutions to the 100 Days of Code – Basic Coding with C activity conducted as part of the academic curriculum at UPES.

The purpose of this activity was to practise C programming regularly, improve problem-solving skills, and understand basic programming concepts through coding.

I completed all 96 days and solved a total of 146 programming questions.

## 📅 Challenge Structure

The challenge was divided into two parts:

### Phase 1: Day 1–50

- 2 questions every day.
- Total: 100 questions.

### Phase 2: Day 51–100

- 1 question every day.
- Total: 50 questions.

Overall: 100 Days | 150 Questions
